# Fluent in Nine website

The website for Fluent in Nine, an Enneagram practice by Katie Hill, Certified Enneagram Facilitator. It's served by GitHub Pages at https://www.fluentinnine.com.

## Pages
- `index.html` is the home page: the motto, the five-part practice, and the two paths.
- `teams.html` covers workshops for teams and organizations, with pricing and how to request a quote.
- `individuals.html` covers sessions, packages, and the free discovery call for individuals and couples.
- `404.html` is the page shown for broken links.

## Editing
All styles live in `css/style.css`. The brand colors are set at the top of that file. To change copy, edit the HTML files directly. GitHub Pages republishes within a minute or two after each commit to `main`.

## Domain
The `CNAME` file holds `www.fluentinnine.com`. DNS for the domain is managed in Cloudflare.
